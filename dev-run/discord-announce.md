# 🔍 CobbleTracker
**Never miss a rare Cobblemon spawn again.**

Rare spawns are easy to walk straight past. CobbleTracker watches every spawn on the server, announces the ones worth chasing, raises a beam of light over them, drops a waypoint on your minimap and keeps a full history — so a Legendary that appeared while you were down a cave is still findable. ✨

## 🔦 In-world spawn beam
A beacon-style column of light stands over a tracked Pokémon for as long as it's in your loaded chunks.
🎨 Coloured by tier — a Legendary reads differently from a Shiny at a glance
🔁 Comes back if you fly off and return
⚡ Vanishes the instant it's caught, defeated or despawns — no ghost beams
⚙️ Radius, grace period and height are all configurable

## 🗺️ Minimap waypoints
Every announcement can carry a clickable **Create Waypoint** link.
📌 Works with **Xaero's Minimap**, **VoxelMap** and **JourneyMap**
🤝 Your client tells the server which ones you actually have — only those formats ever get sent
🙅 No minimap mod required: without one you still get the beam
📍 Clicking a card in the history GUI drops a *past* spawn on your map too

## 📢 Announcements
🔊 Chat announcements with an optional on-screen title and a sound
📡 Broadcast server-wide, or only to players nearby — set per category
🕵️ Optional mode rounds coordinates to the chunk centre, so announcements never hand out pinpoint locations
🖌️ Every line is rewritable with full colour and gradient formatting

=============================== MESSAGE 2 ===============================
## 📖 Spawn history
`/ct` opens a GUI listing everything that has spawned.
🖼️ Sprite cards showing species, biome, coordinates and time
🗂️ A tab per category, plus one for everything at once
↕️ Sort by newest, distance, species, tier or who caught it
💾 Survives server restarts
💬 A plain-chat version works even without the client mod installed

## 🏆 Top Hunters
A built-in leaderboard ranking players by captures. Bragging rights included.

## 🎯 Hunt mode
Press `\` to search the full species list and pick whatever you're hunting.
🟡 Matching Pokémon near you get their own beam
➡️ Directional arrows on your HUD with live distances
🖥️ Entirely client-side — works on any server

## 🧩 Make it yours
📋 Legends, Shinies, Bosses and Ultra Beasts out of the box — add, edit or remove categories freely, each with its own colour, announcement, history and matching rules
⏰ Optional built-in spawner: any category can spawn its tier on a schedule, spread fairly across online players so rates don't balloon on a busy server
🎨 Six GUI themes to switch between
🛠️ In-game admin panel for operators — change settings live, no file editing, no restart

## 📦 Requirements
🧱 Minecraft **1.21.1** · **Fabric** and **NeoForge** · Cobblemon **1.7.0**
🔗 Needs Cobblemon and Architectury API (plus Fabric API and Fabric Language Kotlin on Fabric)
🖧 Install on the server for announcements and history — add it on the client for the beam, GUI, waypoints and hunt mode
